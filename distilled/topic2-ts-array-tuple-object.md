# 1.2 数组、元组 & 对象类型

**它解决什么问题**
JS 数组/对象类型松散，拼错字段、越界、混入错误类型都运行时才炸；TS 给集合类型加形状约束。

**核心机制**
- 数组用 `类型[]`；联合数组必须加括号 `(A|B)[]`，否则 `|` 优先级更低被截断
- 元组 `[A,B,C]` 固定长度异构；字面量初值只推断成普通数组，要元组须显式标注
- 对象可选字段 `field?: T` 读取时是 `T|undefined`，不能直接调方法
- `readonly` 编译期只读防误改；索引签名 `[k:string]:T` 描述 key 不固定的对象

**最容易被追问的点**
- "avatar 可选字段怎么写？" -> `avatar?: string`，不用方括号；`[k:string]` 只用于 key 不固定的索引签名
- "可选链 `?.` 能让输出不显示 undefined 吗？" -> 不能。`?.` 只管访问不报错，不管显示格式；要控制显示必须用条件分支
- "`let t = ['x',1]` 推断成元组吗？" -> 不是，推断成 `(string|number)[]`；要元组须显式标注
- "索引签名和具名字段能共存吗？" -> 会冲突，索引签名约束所有字段，具名字段类型必须兼容它

**一句话类比**
数组像「同款盒子随便装几排」，元组像「固定格子的收纳盒每格指定类型」，可选字段像「盒子上贴了'可能为空'的标签」。
