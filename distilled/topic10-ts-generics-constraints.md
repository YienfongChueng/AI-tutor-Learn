# 3.2 泛型约束（extends）

**它解决什么问题**
无约束泛型 T 上调不了任何成员（x.length 报错，编译器不知 T 有什么）；extends 给 T 设下限，让函数体能安全用成员又保留具体类型。

**核心机制**
- <T extends Shape> 给 T 设形状下限，函数体可安全访问 Shape 成员
- extends 在这是「约束」非「继承」，读作 T 至少满足 Shape
- 约束不擦除 T 具体类型，传入什么 T 还是什么
- K extends keyof T 把 key 限定为 T 的真实键，返回 T[K] 精确到值类型
- 多约束用 & 叠加；类型参数可给默认值 T = any

**最容易被追问的点**
- "extends 在泛型里是继承吗？" -> 不是，是约束；读作「T 至少满足某形状」
- "相比无约束 <T>，extends 新增了什么？" -> 让函数体能安全使用约束形状的成员（保留具体类型是两者都有的）
- "相比基类型 x:HasLength，extends 新增了什么？" -> 保留 T 的具体类型（基类型会丢）
- "keyof 约束返回 T[K] 有什么好处？" -> key 传错编译期报错，返回值精确到该 key 的值类型而非 any

**一句话类比**
无约束泛型像收未知包裹不敢拆；extends 约束像要求包裹至少贴易碎标签，保证能安全按易碎品处理，但包裹本身是什么还是什么。
