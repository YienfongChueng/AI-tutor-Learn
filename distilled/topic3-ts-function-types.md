# 1.3 函数类型（参数/返回值/重载）

**它解决什么问题**
JS 函数不拦参数/返回类型，传错类型、缺参数都运行时才炸；单一签名也无法表达「不同入参对应不同返回」的精确关系。

**核心机制**
- 给参数和返回值加注解，错误前移到编译期
- 用字面量 `(a: T) => U` 表达函数类型，箭头参数名仅占位
- 可选 `?` / 默认 `=值` / 剩余 `...args`，可选参数必须在必填之后
- 重载 = 多个对外签名 + 一个兼容实现，运行时只有一个函数
- 实现签名返回类型取所有重载的联合以兼容

**最容易被追问的点**
- "重载签名参数都写 string 行吗？" -> 不行。宽类型让所有签名坍缩到第一个，重载失效；必须用能区分的字面量当参数类型
- "实现签名对外可见吗？" -> 不可见，调用方只看重载签名；实现签名须兼容所有重载
- "为什么不用联合返回 `A|B` 代替重载？" -> 联合把所有可能揉一起，调用方拿到后还得自己收窄；重载保留「入参->返回」精确对应
- "可选参数能放在必填前面吗？" -> 不能，可选参数必须在必填参数之后

**一句话类比**
重载像菜单点菜，菜名（参数类型）必须不同服务员才分得清；两道菜都叫"炒饭"，只能端出第一道。
