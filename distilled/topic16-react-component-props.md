# 函数组件与 Props（vs SFC）

**它解决什么问题**
建立"组件即函数"的执行模型，这是 hooks 一切行为的根源。

**核心机制**
- 组件 = 接收 props 返回 element 的函数，React 调用你
- 函数体每次渲染都从头执行（Vue setup 只跑一次）
- state 不在函数里，由 React 在外部代管
- 插槽 = 传 JSX/函数当 prop：children=默认插槽，render props=作用域插槽
- key/ref 不进 props；组件须近似纯函数

**最容易被追问的点**
- "setup 和函数组件最大的差异？" -> setup 执行一次闭包住生命周期；函数组件每轮渲染整体重跑
- "渲染期发请求会怎样？" -> 每轮渲染都发；若成功后 setState -> 死循环
- "let count=0 自增为什么不行？" -> 每轮重新初始化 + 局部变量变更通知不到 React
- "谁触发重渲染？" -> 父组件渲染 或 自身 setter 调用，两者都会重新执行函数体
- "hooks 为什么必须在顶层？" -> 函数体反复执行，React 靠调用顺序对号入座

**一句话类比**
Vue 组件像"装修一次住到底的房子"（setup 一次），React 组件像"每次入住重新搭的帐篷"（每次渲染重搭，家当存在 React 的仓库里）。
